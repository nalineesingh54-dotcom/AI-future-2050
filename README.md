## 🧠 Brain Tumor Detection (Hackathon Project)

This project is developed for a Machine Learning Hackathon.

### 📌 Problem
Detect and classify brain tumors from MRI images.

### 🧪 Approach
- Image preprocessing (resizing, normalization)
- CNN model for classification
- Training on 4 classes dataset

### 🧾 Classes
- Glioma Tumor
- Meningioma Tumor
- Pituitary Tumor
- No Tumor

### 📊 Evaluation
- Accuracy
- Precision
- F1 Score
- Confusion Matrix

### 📁 Output
- submission.csv file for Kaggle submission
